# Shambhavi Kumari — Feminine Portfolio

## Files
- index.html — complete portfolio structure/content
- style.css — responsive feminine visual design + animations
- script.js — scroll reveal, cursor glow, smooth navigation

## Run locally
Double-click `index.html`, or open the folder in VS Code and use Live Server.

## Deploy to Vercel
Upload this folder/repository as a static site. `index.html` is already at the root, so no build command is required.

## Content
The portfolio uses the information from the supplied CV. Training is intentionally left as a placeholder because the CV does not provide training details.
